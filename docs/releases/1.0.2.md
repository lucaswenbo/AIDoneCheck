# AIDoneCheck v1.0.2

修复报告和演示说明中英混杂的问题。当前终端提示、Markdown 报告、GitHub Job Summary 和 Agent 反馈说明统一中文。

## 语言与证据

- 检查项、结果说明、警告、阻断问题和证据目录等工具文案显示中文。
- PASS / WARN / BLOCK / SKIP、命令、文件名、JSON 字段及规范化数据保持不变。
- 真实 stdout/stderr、浏览器原始错误和结构化证据保留原文，不翻译或改写。
- GitHub 自身界面及第三方 Actions SDK 日志不由本工具控制。旧运行不会自动更新，需重新运行新版。

## 独立测试仓库

公开演示位于 [AIDoneCheck-Test](https://github.com/lucaswenbo/AIDoneCheck-Test)，调用固定发布版本，覆盖 PASS、WARN、真实测试失败、浏览器 pageerror、关键资源失败及路径错误。

AIDoneCheck 主仓库保留内部回归工作流；它验证当前提交，不代替独立仓库对发布版本的实际消费验证。

## 使用

推荐 `lucaswenbo/AIDoneCheck@v1.0.2`；接受兼容更新可以用 `@v1`。`@main` 用于开发。已有固定 tags 不移动。

```bash
npm install --global https://github.com/lucaswenbo/AIDoneCheck/releases/download/v1.0.2/aidonecheck-1.0.2.tgz
aidonecheck --version
```

没有发布到 npm registry。此版本不修改判定规则、配置 schema 或退出码；发布包和 Action 经真实测试验证。
