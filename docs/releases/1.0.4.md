# AIDoneCheck v1.0.4

English is now the default for the README and tool-generated output. [简体中文文档](https://github.com/lucaswenbo/AIDoneCheck/blob/v1.0.4/README.zh-CN.md) is available through the language link at the top of the README.

## Choose an output language

```bash
aidonecheck check --base origin/main           # English by default
aidonecheck check --base origin/main --lang zh # Simplified Chinese
aidonecheck report --lang zh                  # Render saved JSON; no rerun
```

`--lang en|zh` also works with help, init and doctor. The selected language applies to terminal summaries, diagnostics, saved report.md and agent-feedback.md. JSON fields, canonical messages, raw logs, verdicts and exit codes remain unchanged.

```yaml
- uses: lucaswenbo/AIDoneCheck@v1.0.4
  with:
    language: zh # Defaults to en; includes Job Summary and Markdown evidence.
```

Only en/zh are accepted. Existing evidence is not rewritten, and captured page errors and third-party logs stay verbatim.

## Install

```bash
npm install --global https://github.com/lucaswenbo/AIDoneCheck/releases/download/v1.0.4/aidonecheck-1.0.4.tgz
aidonecheck --version
```

The Release includes both README languages, the CLI package and SHA256SUMS.txt. npm registry publishing remains paused; package-name/npx installation is unavailable. GitHub Release and fixed Action tags remain supported.

简体中文：README 与工具输出默认英文；CLI 加 `--lang zh`、Action 加 `language: zh` 切换中文。不改变配置或 JSON schema，也不翻译原始验证证据。
