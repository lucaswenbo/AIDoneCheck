# AIDoneCheck v1.0.3

修复 Windows 连续验收的报告更新错误，并简化 Release CLI 安装入口。GitHub Release 和 Action 安装方式继续保留；npm registry 分发暂缓。

## Windows 修复

Windows 不能像 Linux 一样直接用新目录链接覆盖已有目录链接。旧版本第一次验收成功，第二次写入 latest 可能发生 EPERM，并错误返回退出码 2。

现在 Windows 使用短时独占锁，先备份旧链接，再发布完整新报告；替换失败时回滚。旧 run 保留，并发写入串行切换。切换有短暂的 latest 缺失窗口；若进程被强制终止留下锁，确认所有检查停止后删除 `.aidonecheck/.latest-lock` 再运行。

Windows Node 20/24 CI 覆盖重复 PASS → BLOCK → PASS、退出码、并发报告、失败回滚和实际安装包。

## 一行安装 CLI

```bash
npm install --global https://github.com/lucaswenbo/AIDoneCheck/releases/download/v1.0.3/aidonecheck-1.0.3.tgz
aidonecheck --version
```

此命令直接安装 Release 附件，无需 clone 或构建源码；Release 继续提供 SHA256SUMS.txt。npm registry 尚未发布，包名安装和 npx 包名入口暂不可用。npm 自动发布默认关闭，待账号认证与受信工作流配置完成后另行启用。

GitHub Action 推荐固定 `lucaswenbo/AIDoneCheck@v1.0.3`；`@v1` 跟随兼容更新。旧版本 tag 不移动。

本次不修改配置 schema、判定规则或 Browser 范围。
